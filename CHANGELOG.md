# Changelog

## 1.0.0 - 2026-10-09
First public release by Rushi.

- From-scratch NumPy neural-network engine (backprop, Adam, cosine LR)
- Dual-Brain detector: autoencoder + classifier + fusion + signature check
- Explainable alerts, Guardian agent with human approval, drift watchdog
- Flask REST API (trains its model automatically on first start)
- Live in-browser lab (GitHub Pages) that trains a network client-side
- 12 automated tests, GitHub Actions CI
- Project report, architecture, design decisions, user guide, viva Q&A
